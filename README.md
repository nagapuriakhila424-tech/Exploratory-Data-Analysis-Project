# Exploratory Data Analysis (EDA) Project

## Project Overview
This project demonstrates a complete Exploratory Data Analysis (EDA) workflow using Python. The dataset was cleaned and preprocessed by handling missing values, removing duplicates, detecting outliers, and analyzing data distributions. Various visualizations were created using Matplotlib and Seaborn to uncover patterns, trends, and relationships within the data. The project provides meaningful insights and prepares the dataset for advanced analytics and machine learning applications.

## Tools and Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Tasks Performed
- Data Loading
- Data Cleaning
- Missing Value Handling
- Duplicate Removal
- Outlier Detection
- Statistical Analysis
- Data Visualization
- Correlation Analysis
