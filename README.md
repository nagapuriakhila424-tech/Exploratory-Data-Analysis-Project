# 📊 Exploratory Data Analysis (EDA) Project

## 🎯 Objective
The objective of this project is to analyze the dataset to extract meaningful insights and understand patterns, trends, and relationships between variables.

---

## 📂 Dataset
- Source: Dataset for Data Analytics.xlsx
- Type: Structured dataset (Excel format)

---

## 🛠 Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

- Data overview and structure analysis
- Descriptive statistics
- Missing value analysis
- Univariate analysis
- Bivariate analysis
- Correlation analysis
- Data visualization using charts

## 📌 Key Insights
- Identified trends and patterns in the dataset

- Generated visual insights using graphs
